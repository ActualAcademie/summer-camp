# 🚀 Summer Camp Web — Guide d'Animation

Bienvenue sur le dépôt officiel du **Summer Camp Web** ! Ce guide détaille le déroulement jour par jour, les ressources à distribuer et les conseils pédagogiques pour assurer une expérience fluide et homogène à l'ensemble des participants.

---

## Structure du dépôt

* `README.md` : Le présent guide pédagogique.
* `slides/` : Supports de présentation au format Markdown (utilisables directement avec l'extension **Marp for VS Code**).
  * `00-intro-kickoff.md`
  * `01-html-css-vscode.md`
  * `02-python-algo.md`
  * `03-bd-sql.md`
  * `04-ihm-kahoot-bilan.md`
* `fiches-cours/` : Fiches récapitulatives en PDF/MD à distribuer aux étudiants.
* `exercices/` : Consignes et ressources de code de départ pour chaque journée.

---

## Déroulement de la semaine & Rôle du Coach

### Jour 1 : Introduction, HTML, CSS & VS Code
**Objectifs** : Comprendre l'architecture du Web (Client/Serveur), structurer une page HTML/CSS, prendre en main l'environnement VS Code.

* **Matin (Concepts & Bac à sable)** :
  * Présentation avec `slides/00-intro-kickoff.md` et `slides/01-html-css-vscode.md`.
  * Explication de l'analogie du restaurant (Front-end = salle, Back-end = cuisine, BDD = garde-manger).
  * Démonstration HTML/CSS en bac à sable / éditeur en ligne.
* **Après-midi (VS Code & Pratique)** :
  * Guide des installations (VS Code + extensions utiles).
  * Exercices pratiques d'intégration web et initiation aux prompts IA pour guider la création HTML/CSS.
* **Fiches à distribuer** : `01-fonctionnement-web.pdf`, `02-html-css.pdf`, `03-vscode.pdf`.

---

### Jour 2 : Algorithmique & Python
**Objectifs** : Découvrir la logique applicative (Back-end), manipuler variables, conditions, boucles et fonctions en Python.

* **Matin (Théorie & Exemples simples)** :
  * Support : `slides/02-python-algo.md`.
  * Explications au tableau : Qu'est-ce qu'un algorithme ? Les types de données, les structures conditionnelles et itératives.
* **Après-midi (Pratique guidée)** :
  * Exercices individuels sur VS Code.
  * **Méthodologie conseillée** : Faire des boucles de correction régulières toutes les 15 à 20 minutes au tableau blanc pour débloquer le groupe.
* **Fiche à distribuer** : `04-python.pdf`.

---

### Jour 3 : Bases de données & SQL
**Objectifs** : Comprendre le rôle d'une base de données relationnelle, modéliser un schéma simple, rédiger des requêtes SQL.

* **Matin (Modélisation & Syntaxe)** :
  * Support : `slides/03-bd-sql.md`.
  * **Étape clé** : Insister sur l'importance du **schéma de données** (le plan de construction). Dessiner des exemples simples au tableau (ex: `Etudiants` et `Cours`).
  * Découverte de la syntaxe SQL de base (`SELECT`, `FROM`, `WHERE`, `ORDER BY`).
* **Après-midi (Pratique sur plateforme)** :
  * Exercices pratiques sur [cours-sql par FX Jollois](https://fxjollois.github.io/cours-sql/).
  * ⚠️ *Astuce d'affichage pour les petits écrans* : Penser à faire baisser le zoom navigateur (`Ctrl -` ou `Cmd -`) si la plateforme manque d'espace.
  * Progression pas à pas avec accompagnement individuel.
* **Fiche à distribuer** : `05-sql.pdf`.

---

### 🔵 Jour 4 : IHM, No-Code & Kahoot de Clôture
**Objectifs** : Comprendre l'Interface Homme-Machine (IHM), assembler une interface web sans code, évaluer les acquis de manière ludique.

* **Matin (IHM & Site123)** :
  * Support : `slides/04-ihm-kahoot-bilan.md`.
  * Introduction aux principes d'IHM / UX basique.
  * Prise en main de **Site123** pour monter rapidement une landing page ou un site vitrine.
* **Après-midi (Bilan & Quiz)** :
  * **Kahoot Final** (12 questions de synthèse couvrant HTML/CSS, Python, SQL et IHM).
  * Rétrospective du Summer Camp, retours d'expérience et conseils pour continuer à monter en compétences.

---

### 🟣 Jour 5 : Journée Modulable & Immersion
**Objectifs** : Présenter son projet personnel, explorer une technologie au choix et vivre une journée d'immersion avec les étudiants de l'école.

* **Matin (Présentations des projets & Travail libre)** :
  * Support : `slides/05-journee-modulable-projets.md`.
  * **Présentations individuelles** : Chaque étudiant présente son projet réalisé durant la semaine (site HTML/CSS, app Python, base de données ou site No-Code).
  * **Atelier libre / Langage au choix** : Poursuite des projets ou découverte d'un nouveau langage/outil au choix selon l'intérêt de l'étudiant (JavaScript, Frameworks, etc.).
* **Après-midi (Immersion & Échanges)** :
  * **Immersion avec les étudiants de l'école** : Temps d'échange, de pair-programming ou de partage d'expérience avec les promotions en cours.
  * **Clôture officielle** : Bilan final du Summer Camp et félicitations aux participants.
