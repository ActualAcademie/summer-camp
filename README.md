# Summer Camp Web — Guide Apprenant

Bienvenue dans le dépôt du **Summer Camp Web**.

Ce dépôt rassemble toutes les ressources dont tu as besoin pendant la semaine pour découvrir le développement web, apprendre les bases de la programmation et réaliser tes premiers projets.

Tu y trouveras les supports de cours, les fiches récapitulatives, les exercices et différentes ressources pour continuer à apprendre après le Summer Camp.

---

## Objectifs de la semaine

À la fin du Summer Camp, tu devrais avoir une première vision globale de la manière dont fonctionne une application web.

Tu vas notamment découvrir :

-   Comment fonctionne le Web
    
-   Le fonctionnement d'une application web
    
-   Le rôle du front-end
    
-   Le rôle du back-end
    
-   Le rôle d'une base de données
    
-   Comment créer une page avec HTML et CSS
    
-   Comment utiliser Visual Studio Code
    
-   Les bases de la programmation avec Python
    
-   Les principes de l'algorithmique
    
-   Le fonctionnement d'une base de données
    
-   Les bases du langage SQL
    
-   Les principes d'IHM et d'UX
    
-   Comment utiliser l'intelligence artificielle comme outil d'aide
    
-   Comment créer un premier projet en utilisant les notions découvertes pendant la semaine
    

L'objectif n'est pas de devenir développeur en quelques jours, mais de **comprendre les grandes notions du développement informatique et de commencer à pratiquer par toi-même**.
